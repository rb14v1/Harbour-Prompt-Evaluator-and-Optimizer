   └─ Loads classification_dataset.json (270 examples, 9 categories)
      ├─ Checks multiple paths
      ├─ Graceful fallback if not found
      └─ Organizes by category for fast lookup

2. DYNAMIC KEYWORD EXTRACTION ✓
   └─ Learns from real data
      ├─ Analyzes all 270 examples
      ├─ Counts word frequencies
      └─ Adds high-frequency terms (≥2 occurrences)

3. SIMILARITY-BASED MATCHING ✓
   └─ Jaccard Similarity: |A ∩ B| / |A ∪ B|
      ├─ Compares prompt to all category examples
      ├─ Returns average similarity (0.0-1.0)
      └─ Handles word variations better

4. HYBRID SCORING ✓
   └─ Weighted combination
      ├─ 40% keyword matching (exact patterns)
      ├─ 60% similarity matching (semantic understanding)
      ├─ +10% boost for strong matches (>0.7)
      └─ -20% penalty for ambiguous cases
